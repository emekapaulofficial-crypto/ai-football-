    03

    How PredictIQ works

    1

    Read the screenshot

    OCR extracts team names and decimal odds. The parser recognizes common markets and keeps uncertain values out rather than inventing them.

    2

    Build team profiles

    Recent results are used to estimate attack, defence, scoring and form. The most recent match receives more weight.

    3

    Run an independent model

    A goal-distribution model estimates expected goals and market probabilities. Bookmaker odds are used for comparison, not copied as the model prediction.

    4

    Rank — or reject

    The system ranks qualifying markets. If evidence is weak or data is missing, it can return no qualifying option instead of forcing a pick.
